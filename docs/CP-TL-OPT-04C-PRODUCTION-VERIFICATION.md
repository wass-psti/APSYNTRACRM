## Runtime implementation inspected

The existing production print path:

1. Loads the selected immutable document revision.
2. Loads the revision bundle and approval evidence.
3. Loads the corresponding Board projection.
4. Retrieves the exact-revision render snapshot through `tl04_document_render_snapshot`.
5. Verifies document identity, revision, approval and Board correspondence.
6. Builds the saved-document printable markup.
7. Loads versioned stylesheets and waits for stylesheet completion, image decoding and document fonts.
8. Calls the browser's native print function.

The output is a Browser Print / Save as PDF copy, not an electronically issued PDF. The existing disclosure that electronic PDF approval and issuance have not been verified must remain intact.
