# APSYNTRA CRM

Huly-derived application development with Supabase PostgreSQL, Auth, Storage and centralized WatchdogWorkspace board permissions.

Development branch: `development/cp-huly-supabase`. This branch contains incremental backend migration components, not a full Huly port. Do not merge to `main` until native Huly integration, authenticated host tests and security/regression acceptance pass.

See `packages/huly-supabase/README.md` for setup and verification. No Docker or local database is required.
