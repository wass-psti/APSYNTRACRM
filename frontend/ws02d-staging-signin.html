This tool uses only the isolated staging Supabase project. It is not the production CRM sign-in. Each account holder can use their own device; do not share credentials or session tokens. Credentials and signed tokens remain in the current browser tab's memory only; close the tab to clear them. Use a private window on a trusted computer.
